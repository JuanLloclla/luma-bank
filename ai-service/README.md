## Requisitos del sistema

### Linux (Fedora/Ubuntu)
- Python 3.10
- python3.10-devel
- gcc-c++

### Windows
- Python 3.10
- Visual Studio Build Tools 2022 (con "Desarrollo de escritorio con C++")

## Instalación
```bash
python -m venv .venv

# Linux
source .venv/bin/activate

# Windows
.venv\Scripts\activate

pip install -r requirements.txt
```
